# Drug Reaction Simulator

A machine learning-based application for simulating and predicting potential drug reactions using patient and drug-related data.

## Overview

Drug Reaction Simulator is a machine learning project designed to analyze drug-related information and predict possible reactions. The project includes data preparation, model training, trained models, and a Python-based application interface.

## Features

- Drug reaction prediction using machine learning
- Dataset preparation and preprocessing
- Model training and evaluation
- Trained model integration
- Python-based application interface
- Organized dataset and model directories
